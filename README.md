## Подготовка окружения в PowerShell

Требуется обычная Windows-сборка Python 3.11 или новее. В этой папке команда
`python` может указывать на MSYS2 без pip, поэтому используется Windows launcher `py`.

```powershell
py -3.11 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r ЛР2/requirements.txt -r ЛР3/requirements.txt -r ЛР4/requirements.txt -r ЛР5/requirements.txt -r ЛР6/requirements.txt
```

Команды запуска отдельных работ приведены в их README. Для ЛР3 и ЛР4 запускаются
две независимые проверки: `python -m unittest discover -s tests -v` и `python -m behave`.
Команды выполняются из соответствующей папки работы.

## Telegram

ЛР5 и ЛР6 используют `python-telegram-bot==22.8`. Каждому боту рекомендуется
создать собственный токен через BotFather. В PowerShell задайте токен локально:

```powershell
$env:TELEGRAM_BOT_TOKEN = 'ваш_токен'
../.venv/Scripts/python.exe main.py --telegram
```

Эту команду выполняйте из папки ЛР5 или ЛР6. Бот работает, пока запущена программа.
ЛР6 предназначена для личных сообщений; данные диалога хранятся в памяти и
сбрасываются при перезапуске. Два процесса с одним токеном одновременно запускать нельзя.
Файлы `.env.example` показывают имя переменной; автоматическое чтение `.env` не используется.
Токены в репозитории отсутствуют.

Без токена доступны реальные обработчики в локальной демонстрации:

```powershell
../.venv/Scripts/python.exe main.py --demo
../.venv/Scripts/python.exe -m unittest discover -s tests -v
```

Экранные формы в отчетах ботов относятся к локальной демонстрации.
Подключение к Telegram API и диалог в Telegram без личного токена не проверялись.

## Ручной ввод своих значений

Откройте `main.py` нужной работы и нажмите ▶ в VS Code. Программа покажет меню
в панели **Терминал**: выберите задачу, введите свои значения и посмотрите вывод.
Обычный запуск всех `main.py` открывает ручной режим; `--demo` показывает готовый пример.
В ЛР1 ввод коэффициентов уже предусмотрен в обоих файлах решения уравнения.

В ЛР2 и ЛР3 вводятся фигура и размеры; в функциональной работе доступны все семь
задач со своими данными; в ЛР4 можно собрать заказ из напитка, молока и скидки.
ЛР5 и ЛР6 по умолчанию запускают локальный диалог бота без токена.
Подключение к Telegram запускается с `--telegram`.

Для проверки меню из корня проекта:

```powershell
./.venv/Scripts/python.exe scripts/check_interactive.py
```

## Пересборка отчетов

```powershell
./.venv/Scripts/python.exe -m pip install -r scripts/requirements-reports.txt
./.venv/Scripts/python.exe scripts/build_reports.py
```

Скрипт повторно запускает проверки и примеры, формирует Markdown и PDF,
создает изображения консольного вывода. Временные изображения страниц для
визуальной проверки находятся в игнорируемой папке `tmp/pdf_qa`.
