## Основные конструкции языка Python.

**Дисциплина:** Алгоритмические языки и программирование (АССОИУ)
**Язык реализации:** Python

## 1. Цель работы

Разработать консольное приложение на языке Python для решения биквадратного
уравнения вида

    A * x^4 + B * x^2 + C = 0

Программа должна вводить коэффициенты A, B, C с клавиатуры либо принимать
их в виде параметров командной строки, вычислять дискриминант
вспомогательного квадратного уравнения и находить все **действительные**
корни исходного уравнения.

Дополнительно (доп. задание 1) реализовать два варианта программы:

- с применением **процедурной** парадигмы программирования;
- с применением **объектно-ориентированной** парадигмы программирования.

## 2. Постановка задачи

Биквадратное уравнение `A*x^4 + B*x^2 + C = 0` заменой `t = x^2` сводится к
квадратному уравнению относительно `t`:

    A * t^2 + B * t + C = 0

Дискриминант вспомогательного уравнения:

    D = B^2 - 4 * A * C

В зависимости от знака `D` вспомогательное уравнение имеет:

- при `D > 0` — два различных действительных корня `t1`, `t2`;
- при `D = 0` — один (двукратный) действительный корень `t`;
- при `D < 0` — действительных корней нет, следовательно, у исходного
  биквадратного уравнения тоже нет действительных корней.

Для каждого найденного корня `t` восстанавливаются корни исходного
уравнения `x`:

- если `t > 0`, то `x = ±sqrt(t)` (два действительных корня);
- если `t = 0`, то `x = 0` (один корень);
- если `t < 0`, то действительных корней `x` для данного `t` не существует
  (`sqrt(t)` — мнимое число).

Отдельно обрабатывается вырожденный случай `A = 0`, когда уравнение
перестаёт быть биквадратным в строгом смысле:

- `A = 0, B ≠ 0` — уравнение линейно относительно `t`: `t = -C / B`;
- `A = 0, B = 0, C = 0` — тождество `0 = 0`, бесконечное множество решений;
- `A = 0, B = 0, C ≠ 0` — решений нет.

### Требование к вводу коэффициентов

Коэффициенты могут быть заданы параметрами командной строки:

    python biquadratic.py -a <A> -b <B> -c <C>

Если какой-либо коэффициент не задан в командной строке или задан
некорректно (не может быть без ошибок преобразован в действительное
число), то некорректное/отсутствующее значение игнорируется, и программа
запрашивает соответствующий коэффициент с клавиатуры, повторяя запрос до
тех пор, пока не будет введено корректное значение.

## 3. Алгоритм решения

1. Получить коэффициенты A, B, C (из командной строки либо с клавиатуры,
   с проверкой корректности каждого значения).
2. Если `A ≠ 0`, вычислить дискриминант `D = B^2 - 4*A*C` вспомогательного
   квадратного уравнения; в зависимости от знака `D` найти корни `t`.
   Если `A = 0`, обработать вырожденный (линейный/тождественный) случай.
3. Для каждого найденного корня `t` вычислить соответствующие
   действительные корни `x` исходного уравнения по правилам, описанным в
   разделе 2.
4. Вывести значение дискриминанта и найденные действительные корни `x`
   (или сообщение об их отсутствии / бесконечном множестве решений).

## 4. Листинги программ

### 4.1. Процедурная реализация (`procedural/biquadratic.py`)

Ключевые функции:

- `to_float(value)` — безопасное преобразование строки в `float`.
- `read_coefficient(name, cli_value)` — получение корректного значения
  коэффициента (из CLI-параметра либо повторным запросом с клавиатуры).
- `solve_quadratic_for_t(a, b, c)` — решение вспомогательного уравнения
  относительно `t` с учётом вырожденных случаев `a = 0`.
- `solve_biquadratic(a, b, c)` — вычисление дискриминанта и списка
  действительных корней `x`.
- `main()` — точка входа: разбор аргументов, ввод коэффициентов, вывод
  результата.

Полный текст программы — см. файл `procedural/biquadratic.py`.

### 4.2. Объектно-ориентированная реализация (`oop/biquadratic_oop.py`)

Использованные классы:

- `CoefficientReader` — инкапсулирует логику получения корректного
  значения коэффициента (из CLI либо с клавиатуры).
- `BiquadraticEquation` — хранит коэффициенты `a, b, c`, вычисляет
  дискриминант и действительные корни (`solve()`), формирует текстовый
  отчёт о результате (`report()`).
- `Application` — управляет разбором аргументов командной строки, вводом
  коэффициентов через `CoefficientReader` и выводом результата.

Полный текст программы — см. файл `oop/biquadratic_oop.py`.
